# Offline benchmark results

PikaCore includes a deterministic evaluation harness for its implemented safety,
scheduling, recovery, Working Memory, and context behavior. It uses isolated fixture
repositories and `ScriptedFakeLLM`; it does not call a real API by default.

## Run the suite

```bash
uv run python benchmarks/run_benchmarks.py --ablation all
```

The default JSON report is written to:

```text
.pikacore/benchmarks/phase6-report.json
```

Run a subset or one variant with:

```bash
uv run python benchmarks/run_benchmarks.py --fixture path-escape --ablation baseline
uv run python benchmarks/run_benchmarks.py --ablation working-memory-off
uv run python benchmarks/run_benchmarks.py --ablation context-policy-off
```

Baseline failures return a non-zero exit code. Expected differences in feature-off
ablations are recorded in the report but do not make the CLI fail when the baseline is
healthy.

## Fixture coverage

| Fixture | Contract exercised |
|---|---|
| `edit-basic` | Structured edit and resulting file content. |
| `bad-args-retry` | Bad tool arguments produce a paired error and allow a corrected retry. |
| `path-escape` | A path outside the workspace is rejected. |
| `permission-reject` | Ask-mode rejection prevents mutation. |
| `parallel-read` | Consecutive reads execute concurrently and return in requested order. |
| `write-barrier` | A write is serialized between reads and its result is visible afterward. |
| `large-output` | Large tool output triggers the implemented context policy and trace metrics. |
| `resume-stale-file` | External file changes classify recovery as stale. |
| `resume-unknown-write` | Pending mutation is repaired as interrupted without replay. |
| `working-memory-stale` | Working Memory carries file state and recovery freshness. |

Every fixture declares an explicit manifest. The runner copies only listed regular
files, rejects traversal and symlinks, and runs in a temporary directory. Local cache,
`.env`, ignored files, and generated bytecode are not copied.

## Supported variants

The harness implements exactly three configurations:

| Variant | Working Memory | Context policy |
|---|---:|---:|
| `baseline` | on | on |
| `working-memory-off` | off | on |
| `context-policy-off` | on | off |

combined pass rate is 93.33%. These numbers describe deterministic scripted fixtures,
not general coding quality or real-model success rates.

## Reproducibility contract

For a fixed fixture manifest and fake-response script, outcome comparison excludes
timestamps, wall-clock duration, UUIDs, temporary paths, and other non-deterministic
fields. The compared outcome contains completion, pass/fail checks, model attempts,
tool steps, scripted prompt/completion tokens, approvals, compression count, recovery
status, stop reason, and failure categories.

The JSON report still includes generation time and duration for observation, but
`deterministic_dict()` omits them. Interrupts such as `KeyboardInterrupt` and
`SystemExit` propagate instead of being converted into ordinary benchmark failures.
